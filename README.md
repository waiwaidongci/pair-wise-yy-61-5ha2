# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、离线暂存、冲突提交提示、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 转站接收（合并批次）

外站半包转来时在「转站接收」页按批次认领：

- **认领键 = 工卡编号 + 飞机登记号**：登记号不属于当前包（B-7891）的记录不认领并单独提示。
- **无冲突并入**：测量值、证据（按编号去重）、阶段签署（同阶段同签署人只签一次）、放行单和完成数直接并进当前包，完成数与放行单不再重复。
- **不一致即挂起**：两座机库测量值、同编号证据名称、同阶段签署人或放行结论不一致时，工卡挂起，两套原值完整保留；接线员在侧栏选定一份来源值解挂，相关签字仍需重算重签。
- **补交即失效**：测量值或证据补交后，对应阶段签字与放行结论立即失效，放行门禁实时重算，重签后方可再次锁定。
- **批次号只成一次**：两座机库同时提交同一批次时服务端合流；批次号重复提交返回既有结果，绝不二次成批。
- **失败回退 + 重试补差**：首次写入失败时仅首批工卡落盘并整体报错，客户端回到接站前不应用任何改动；重试只提交尚未并入的工卡（按 `工卡@机库` 去重）。
- **旧包兼容**：没有来源机库标记的记录按「本站历史」兼容并入（同值合并、异值仍挂起）；旧版本 localStorage 状态自动迁移。

React、Fluent UI、Redux Toolkit、React Router、RTK Query、Vite、TypeScript。
